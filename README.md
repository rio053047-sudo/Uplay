# Uplay 💜

A modern dating and social connection app with real-time chat, user discovery, and mutual matching.

## Features

✨ **Core Features**
- User signup and login system
- Comprehensive user profiles with bio, interests, and location
- Nearby users discovery with distance calculation
- Like, pass, and mutual match system
- One-to-one real-time chat after matching
- Advanced search and filters (age, distance, interests)
- Profile verification badge
- Report and block user functionality
- Privacy and location controls

🎨 **Design**
- Clean, modern, mobile-first design
- Blue-purple gradient theme
- Smooth animations and transitions
- Intuitive bottom navigation
- Responsive layout

📱 **Screens**
1. **Home** - Dashboard with stats, trending users, and suggestions
2. **Discovery** - Browse nearby users with filtering options
3. **Matches** - View mutual matches and conversation list
4. **Chat** - Real-time messaging with match connections
5. **Profile** - User profile management and verification
6. **Settings** - Privacy controls, notifications, and account settings

## Getting Started

1. Open `index.html` in a web browser
2. Navigate using the bottom navigation bar
3. Explore features and test the prototype
